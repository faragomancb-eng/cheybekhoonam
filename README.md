# چی بخونم؟

پیشنهاد کتاب **ادبیات گمانه‌زن** (علمی‌تخیلی، فانتزی، وحشت، پادآرمان‌شهر، ویرد، رئالیسم جادویی) بر اساس حس‌وحال خواننده — بخشی از [فراگمان](https://faragomancb.ir).

خواننده هر چی دلش می‌خواد می‌نویسد («خسته‌ام، یه چیز رازآلود و دنج، زیر ۳۰۰ صفحه»، «شبیه تل‌ماسه ولی کوتاه‌تر»، «مثل اینترستلار»)، سایت برداشتش را به شکل برچسب‌های قابل‌حذف نشان می‌دهد و کتاب‌ها را با دلیل پیشنهاد می‌کند. همه‌چیز در مرورگر خود کاربر اجرا می‌شود؛ سرور، پایگاه‌داده و حساب کاربری لازم نیست.

> `data/books.json` حدود هزار کتاب گمانه‌زن دارد (۳۵ کتاب آزمایشی اول + کتاب‌های تازه). فهرست از Wikidata (آثار شناخته‌شده‌ی ژانرهای گمانه‌زن، مرتب‌شده بر اساس شهرت، حداکثر ۳ جلد از هر مجموعه و ۱۰ کتاب از هر نویسنده) ساخته شده و برچسب‌های حس‌وحال/مایه/سرعت/تاریکی دستی زده شده‌اند.
>
> **ترجمه‌ی فارسی:** هر کتاب با عنوان فارسی و نام نویسنده در طاقچه جست‌وجو شده؛ فقط وقتی هم عنوان و هم نویسنده جور بوده، `translated: true` شده و مترجم‌ها (حداکثر ۳ مترجم پرتکرار) و لینک طاقچه (`link`) ثبت شده است. نسخه‌های «خلاصه‌ی کتاب» و نسخه‌های انگلیسی حذف شده‌اند. اگر در طاقچه نبود و ویکی‌پدیای فارسی مترجم داشت، از آن‌جا آمده و در `note` نوشته شده. بقیه `translated: false` با توضیح در `note` هستند — یعنی «ترجمه‌ای پیدا نشد»، نه لزوماً «ترجمه نشده»؛ ترجمه‌های فقط‌چاپی یا با عنوان خیلی متفاوت ممکن است از قلم افتاده باشند. مترجم‌های اشتباه ۳۵ کتاب آزمایشی هم با همین روش اصلاح شدند.

## انتشار در GitHub Pages

۱. یک مخزن تازه در GitHub بسازید و محتوای این پوشه را در شاخه‌ی `main` بگذارید (یا فایل zip را باز کنید و همه را push کنید). پوشه‌ی پنهان `.github` هم باید بیاید.
۲. در مخزن: **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** بگذارید.
۳. یک بار در تب **Actions** گردش‌کار «انتشار در GitHub Pages» را اجرا کنید (یا یک commit بزنید). چند دقیقه بعد سایت روی `https://USERNAME.github.io/REPO/` بالا است.

گردش‌کار در هر انتشار این‌ها را انجام می‌دهد:

- `npm run validate` — اگر فایل کتاب‌ها خطا داشته باشد، انتشار متوقف می‌شود و سایت خراب منتشر نمی‌شود؛
- `npm test`؛
- `npm run prefetch` — خلاصه و جلد کتاب‌های تازه را از ویکی‌پدیا / Google Books / Open Library می‌گیرد و چند نوشته‌ی آخر فراگمان را از RSS. اگر این مرحله شکست بخورد، سایت با داده‌های قبلی منتشر می‌شود؛
- خلاصه‌های تازه در خود مخزن commit می‌شوند تا دفعه‌ی بعد از اول گرفته نشوند؛
- انتشار. هر روز ساعت ۰۳:۳۰ UTC هم خودکار تکرار می‌شود. هر اجرا حداکثر ۶۰۰ کتاب تازه یا ۴۵ دقیقه کار می‌کند، پس برای هزار کتاب چند روز طول می‌کشد تا همه‌ی خلاصه‌ها جمع شوند (تا آن موقع خلاصه‌ی بقیه در مرورگر بازدیدکننده گرفته می‌شود).

برای commit خودکار، در Settings → Actions → General → Workflow permissions گزینه‌ی **Read and write** را بزنید.

**روش ساده‌تر (بدون Actions):** Source را روی **Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` بگذارید. سایت کار می‌کند، فقط بررسی خودکار و به‌روزرسانی خلاصه‌ها را ندارید؛ در این حالت بعد از افزودن کتاب، `npm run prefetch` را روی کامپیوتر خودتان اجرا و نتیجه را commit کنید.

**دامنه‌ی اختصاصی** (مثلاً `books.faragomancb.ir`): در همان صفحه‌ی Pages قسمت Custom domain را پر کنید و یک رکورد CNAME به `USERNAME.github.io` بسازید. همه‌ی مسیرها نسبی‌اند، پس زیرپوشه یا دامنه فرقی نمی‌کند.

## افزودن و ویرایش کتاب‌ها

تنها فایلی که معمولاً دست می‌خورد `data/books.json` است. هر کتاب یک شیء است:

```json
{
  "id": "dune",
  "title": "تل‌ماسه",
  "title_en": "Dune",
  "author": "فرانک هربرت",
  "author_en": "Frank Herbert",
  "translators": ["کاوه میرعباسی"],
  "year": 1965,
  "pages": 680,
  "genres": ["sf", "space-opera"],
  "moods": ["epic", "philosophical", "tense"],
  "themes": ["politics", "ecology", "religion"],
  "pace": 3, "darkness": 3, "complexity": 4,
  "warnings": ["violence"],
  "films": ["لورنس عربستان (Lawrence of Arabia)"],
  "wiki_en": "Dune (novel)"
}
```

### فیلدها

| فیلد | لازم؟ | توضیح |
|---|---|---|
| `id` | **بله** | شناسه‌ی یکتا، فقط حروف کوچک انگلیسی، عدد و `-` (مثل `left-hand-of-darkness`). در لینک‌ها و قفسه‌ی کاربر ذخیره می‌شود؛ بعد از انتشار عوضش نکنید. |
| `title` | **بله** | عنوان فارسی. اگر کتاب نام دیگری هم دارد داخل پرانتز بیاورید: `"خلع‌شدگان (بی‌پناهان)"` — هر دو نام در جست‌وجو شناخته می‌شوند. |
| `author` | **بله** | نام فارسی نویسنده. |
| `title_en`, `author_en` | توصیه‌شده | نام اصلی؛ برای جست‌وجو و پیدا کردن خودکار خلاصه و جلد خیلی مهم است. |
| `genres` | توصیه‌شده | فهرست شناسه‌ی ژانر (جدول پایین). اولی مهم‌تر است. |
| `moods` | توصیه‌شده | حس‌وحال‌ها **به ترتیب غلبه**؛ اولی بیشترین وزن را دارد. ۲ تا ۴ مورد کافی است. |
| `themes` | اختیاری | مایه‌ها (جدول پایین). مایه‌ای را بزنید که واقعاً محور کتاب است، نه هر چیزی که یک بار آمده. |
| `pace` | اختیاری | ریتم، ۱ (آرام) تا ۵ (نفس‌گیر). |
| `darkness` | اختیاری | تلخی و خشونت، ۱ (روشن و گرم) تا ۵ (خیلی تلخ). |
| `complexity` | اختیاری | سختی خواندن، ۱ (خوش‌خوان) تا ۵ (سنگین). |
| `pages` | اختیاری | تعداد صفحه‌ی ترجمه‌ی فارسی. برای «زیر ۳۰۰ صفحه» و تخمین زمان خواندن. |
| `year` | اختیاری | سال انتشار اصلی. |
| `translators` | اختیاری | فهرست مترجم‌ها. فقط نام مترجم؛ «در دست ترجمه» و توضیح ننویسید (برای توضیح `note`). |
| `translated` | اختیاری | `true`/`false`. اگر ننویسید، از روی وجود مترجم حدس زده می‌شود. فیلتر «فقط ترجمه‌شده‌ها» از این استفاده می‌کند. |
| `series`, `series_number` | اختیاری | نام مجموعه و شماره‌ی جلد. |
| `format` | اختیاری | `novel` (پیش‌فرض)، `novella`، `collection`، `graphic`. |
| `audience` | اختیاری | `adult` (پیش‌فرض)، `ya` نوجوان، `all` همه‌ی سنین. |
| `warnings` | اختیاری | هشدار محتوا (جدول پایین). کاربر می‌تواند این‌ها را کاملاً کنار بگذارد. |
| `films` | اختیاری | فیلم/سریال‌های هم‌حس، به شکل `"فارسی (English)"`. وقتی کاربر بنویسد «مثل بلید رانر» از این‌ها استفاده می‌شود. |
| `awards` | اختیاری | فهرست جایزه‌ها، متن آزاد. |
| `quote` | اختیاری | یک جمله‌ی کوتاه از کتاب. |
| `isbn` | اختیاری | شابک ۱۰ یا ۱۳ رقمی؛ برای پیدا کردن جلد. |
| `wiki_en`, `wiki_fa` | اختیاری | عنوان دقیق مقاله‌ی ویکی‌پدیا، اگر جست‌وجوی خودکار مقاله‌ی اشتباه پیدا کرد. مثل `"Solaris (novel)"`. |
| `summary` | اختیاری | خلاصه‌ی دستی. فقط وقتی بنویسید که خلاصه‌ی خودکار بد یا ناموجود است؛ اگر باشد، همیشه همین نمایش داده می‌شود. |
| `cover` | اختیاری | آدرس تصویر جلد (`https://…` یا `assets/covers/dune.jpg`). اگر نباشد، جلد خودکار پیدا می‌شود و در بدترین حالت یک جلد ساده‌ی تایپوگرافیک ساخته می‌شود. |
| `link` | اختیاری | لینک خرید یا معرفی کتاب. فقط اگر واقعاً صفحه‌ای وجود دارد. |
| `featured` | اختیاری | `true` یعنی در صفحه‌ی اول، پیش از هر جست‌وجو، نشان داده شود. |
| `note` | اختیاری | یادداشت داخلی؛ در سایت نمایش داده نمی‌شود. |

### شناسه‌های مجاز

**حس‌وحال (`moods`):** `dark` تاریک · `hopeful` امیدبخش · `cozy` دنج و گرم · `tense` پرتعلیق · `melancholic` غمگین و نوستالژیک · `philosophical` فلسفی و ژرف · `epic` حماسی · `adventurous` پرماجرا · `eerie` وهم‌آلود · `funny` بامزه · `wonder` شگفت‌انگیز · `romantic` عاشقانه · `mysterious` رازآلود

**ژانر (`genres`):** `sf` علمی‌تخیلی · `hard-sf` علمی‌تخیلی سخت · `space-opera` اپرای فضایی · `cyberpunk` سایبرپانک · `military-sf` علمی‌تخیلی نظامی · `fantasy` فانتزی · `epic-fantasy` فانتزی حماسی · `grimdark` گریمدارک · `urban-fantasy` فانتزی شهری · `magical-realism` رئالیسم جادویی · `weird` ویرد · `horror` وحشت · `dystopia` پادآرمان‌شهر · `post-apocalyptic` پساآخرالزمانی

زیرژانرها والد دارند (`hard-sf` ← `sf`)؛ کسی که «علمی‌تخیلی» بخواهد، علمی‌تخیلی سخت را هم می‌بیند. لازم نیست هر دو را بنویسید، ولی ضرری ندارد.

**مایه‌ها (`themes`):** `ai` هوش مصنوعی · `artificial-life` آدم‌مصنوعی و ربات · `virtual-worlds` دنیای مجازی · `time` زمان و سفر در زمان · `aliens` بیگانه‌ها و تماس اول · `space-travel` سفر فضایی · `science` علم و مهندسی · `evolution` تکامل · `ecology` طبیعت و محیط‌زیست · `politics` سیاست و قدرت · `empire` امپراتوری · `war` جنگ · `totalitarian` حکومت تمامیت‌خواه · `utopia` آرمان‌شهر · `religion` دین و ایمان · `myth` اسطوره و خدایان · `chosen-one` قهرمان برگزیده · `quest` سفر و جست‌وجو · `friendship` دوستی و رفاقت · `coming-of-age` بزرگ شدن · `academy` مدرسه و آکادمی · `magic-system` سیستم جادویی · `dragons` اژدها و موجودات افسانه‌ای · `heist` سرقت و نقشه · `mercenaries` مزدورها · `morally-grey` شخصیت‌های خاکستری · `survival` بقا · `isolation` تنهایی و انزوا · `identity` هویت و انسان بودن · `gender` جنسیت · `language` زبان · `labyrinth` هزارتو · `books-knowledge` کتاب و دانش · `art` هنر و موسیقی · `pandemic` همه‌گیری

**هشدار محتوا (`warnings`):** `violence` خشونت · `gore` صحنه‌های خون‌آلود · `torture` شکنجه · `sexual` محتوای جنسی · `suicide` خودکشی · `child-harm` آسیب یا مرگ کودک · `drugs` مواد مخدر · `body-horror` وحشت بدن · `grief` سوگ · `mental-illness` افسردگی و بیماری روان · `slavery` برده‌داری · `abuse` آزار روانی · `spiders` عنکبوت · `profanity` زبان رکیک

شناسه‌ی ناشناخته باعث خرابی نمی‌شود: آن برچسب نادیده گرفته می‌شود و `npm run validate` هشدار می‌دهد. ردیفی که `id`، `title` یا `author` نداشته باشد کنار گذاشته می‌شود و بقیه‌ی سایت کار می‌کند.

### به‌جای JSON، از Excel یا Google Sheets

اگر کار با جدول راحت‌تر است، `data/books.template.csv` را باز کنید، ردیف‌ها را پر کنید و با نام `data/books.csv` (UTF-8) ذخیره کنید. بعد در `js/config.js` بنویسید:

```js
booksUrl: './data/books.csv',
```

ستون‌ها همان فیلدهای بالا هستند. در ستون‌های فهرستی (`genres`، `moods`، `translators`، …) مقدارها را با `|` جدا کنید: `sf|space-opera`.

### افزودن حس‌وحال، ژانر یا مایه‌ی تازه

در `data/vocab.json` یک مورد به گروه مربوط اضافه کنید:

```json
{ "id": "cosmic", "label": "کیهانی", "near": ["wonder"], "aliases": ["کیهانی", "کهکشانی", "cosmic"] }
```

- `aliases` کلمه‌هایی است که اگر کاربر در متن آزاد بنویسد، این گزینه تشخیص داده می‌شود. شکل‌های رایج نوشتاری و محاوره‌ای را بیاورید؛ نیم‌فاصله، «ي/ی» و «ك/ک» خودکار یکسان می‌شوند. علامت `=` در ابتدای کلمه یعنی فقط همان کلمه‌ی دقیق، نه کلمه‌هایی که با آن شروع می‌شوند (`=سیاه` با «سیاهچاله» اشتباه نمی‌شود).
- `near` (فقط حس‌وحال) حس‌های نزدیک؛ اگر کتابی دقیقاً آن حس را نداشت ولی حس نزدیکش را داشت، امتیاز کمتری می‌گیرد به‌جای صفر.
- `parent` (فقط ژانر) ژانر والد.

## خلاصه‌ی کتاب‌ها از کجا می‌آید

هیچ خلاصه‌ای لازم نیست دستی نوشته شود. به ترتیب:

۱. فیلد `summary` در خود کتاب، اگر نوشته باشید؛
۲. `data/summaries/00.json` تا `63.json` (۶۴ تکه؛ هر کتاب با هش شناسه‌اش در یک تکه است و فقط وقتی کسی کتاب را باز کند، همان تکه دانلود می‌شود) و `data/covers.json` (فقط آدرس جلدها، برای کارت‌ها) که `npm run prefetch` می‌سازد: ویکی‌پدیای فارسی ← Google Books فارسی ← ویکی‌پدیای انگلیسی ← Google Books ← Open Library. منبع هر خلاصه زیرش نوشته می‌شود؛
۳. اگر کتابی تازه اضافه شده و هنوز در آن فایل نیست، همان جست‌وجو در مرورگر بازدیدکننده انجام و ۳۰ روز ذخیره می‌شود.

مرحله‌ی ۲ مهم است: ویکی‌پدیا و گوگل برای بخشی از کاربران در ایران در دسترس نیستند، ولی این فایل‌ها روی خود سایت است و همیشه باز می‌شود. اگر خلاصه‌ی یک کتاب اشتباه بود، `wiki_en`/`wiki_fa` را دقیق کنید و `npm run prefetch -- --only=book-id` بزنید، یا `summary` دستی بنویسید.

کلید Google Books اختیاری است؛ اگر سهمیه‌ی رایگان کم آمد، کلید را در Settings → Secrets → Actions با نام `GOOGLE_BOOKS_API_KEY` بگذارید.

## تنظیمات

همه در `js/config.js`: نام سایت و سایت مادر، مسیر فایل کتاب‌ها، روشن/خاموش بودن جست‌وجوی زنده‌ی خلاصه، تعداد نتیجه در هر صفحه و سرعت پیش‌فرض خواندن (صفحه در ساعت، برای «حدود ۸ ساعت»).

رنگ‌ها و فونت‌ها در ابتدای `css/main.css` به صورت متغیر تعریف شده‌اند. تصویر پس‌زمینه `assets/img/hero-night.webp` (و نسخه‌ی موبایل) است؛ با هر تصویر افقی تیره‌ای قابل تعویض است.

## اجرای محلی

Node.js 20 یا بالاتر لازم است؛ وابستگی دیگری ندارد (`npm install` لازم نیست).

```bash
npm start            # http://localhost:8080
npm run validate     # بررسی فایل کتاب‌ها
npm test             # آزمون‌های موتور پیشنهاد و پارسر متن
npm run prefetch     # خلاصه‌ی کتاب‌هایی که هنوز گرفته نشده‌اند
# گزینه‌ها: -- --limit=200  --minutes=20  --only=id1,id2  --retry-missing  --force
```

باز کردن مستقیم `index.html` با دوبار کلیک کار نمی‌کند (مرورگر اجازه‌ی خواندن فایل‌های JSON را نمی‌دهد)؛ از `npm start` استفاده کنید.

چیزی به سرور فرستاده نمی‌شود. قفسه‌ی کاربر («می‌خوام بخونم»، «خوندمش»، «برام جذاب نیست») فقط در مرورگر خودش ذخیره می‌شود و از داخل قفسه قابل خروجی‌گرفتن و برگرداندن است. تنها درخواست بیرونی، جست‌وجوی خلاصه و جلد برای کتاب‌هایی است که خلاصه‌شان هنوز در `data/summaries/` نیست.
